# Changelog

## v0.4.0 (2026-09-12)

- Show file names, prompt age, change totals, and restore effects when rewinding.
- Include restored file names in completion messages, shortening long paths and lists.
- Allow rolling back a checkpoint commit immediately after it was amended.

## v0.3.0 (2026-08-28)

- Rewind can reset Git commits created after a checkpoint before restoring checkpointed files.

## v0.2.0 (2026-08-26)

- Configure whether interrupting an active response requires one or two Escape presses and customize the Escape detection window.

## v0.1.1 (2026-08-20)

- Rewind conversations within the current session instead of creating a new branch.

## v0.1.0 (2026-08-15)

- Initial release
